# Uter Product Scope

**Knowledge status:** DRAFT — scope outline, not an approved product requirements baseline.

## Candidate capability areas requiring source confirmation

- API relay and upstream provider/model routing.
- User, team, and access-key management.
- Usage measurement, token accounting, quota, and billing.
- Payment, recharge, refund, and balance management.
- Administrative configuration and operational monitoring.
- Web and Electron client experiences.
- Documentation and integration support.

## Scope control

A feature is IN_SCOPE only when supported by an approved requirement or current product behavior. Planned, experimental, disabled, and deprecated capabilities must be labeled separately. This file does not authorize implementation or changes to financial behavior.
