# Product Documentation

## 1. 文档分类

产品文档包括：

- Product Brief。
- PRD。
- User Story。
- Business Rules。
- User Flow。
- State Machine。
- Acceptance Criteria。
- Change Record。
- Release Notes。

## 2. 文档管理

每份正式文档必须记录：

- Document ID。
- Version。
- Status。
- Owner。
- Created Date。
- Updated Date。
- Related Requirements。
- Related Standards。

## 3. 文档一致性

需求发生变更时，必须判断相关产品文档是否需要同步。

不得让已经废弃的业务规则继续被 AI 当作现行规则使用。
